# Frontend — Misconception Mapper (MM)

React + Tailwind CSS client application for student diagnostic sessions, explainable diagnosis results, remediation, verification, and analytics dashboards.

## Key Views
- **Adaptive Quiz & Diagnostic Screen**: Question presenter with tactile 1–5 confidence control.
- **Explainable Diagnosis Card**: Transparent "Why We Think This" step-by-step evidence viewer.
- **Targeted Remediation & Different-Form Verification**: Interactive conceptual repair and verification challenge.
- **Student Dashboard & Knowledge-Gap Map**: Dynamic skill visualization and calibration insights.
- **Teacher View**: Cohort misconception heatmaps and reteaching recommendations.
